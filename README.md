# 🚲 자전거로어스 (bicycleroers)

귀여운 2등신 캐릭터가 다양한 자전거를 타고 3D 마을을 달리며 다른 사람들과 실시간으로 소통하는 놀이터입니다.

- **Next.js 16** (App Router) + **React Three Fiber / three.js** 3D
- **Supabase (yahomi 프로젝트)**: 채팅·랭킹 저장(Postgres), 실시간 위치·감정표현(Realtime Broadcast/Presence)

## 기능
- 자전거 9종: 로드바이크, 산악자전거, BMX, 크루저, 픽시, 미니벨로, 세발자전거, 외발자전거, 2인용 탠덤(곰돌이 동승)
  - 종류마다 속도·가속·회전·점프 성능이 다름 (산악자전거는 잔디에서도 감속 없음)
- 캐릭터 꾸미기: 옷 색깔 8종, 모자 6종 (헬멧/캡모자/토끼귀/비니/왕관/없음)
- 감정표현: 🙇 큰절(B) · 👋 인사(H) · 🙌 만세(C) — 다른 플레이어에게도 보임
- 실시간 멀티플레이: 접속자 위치, 이름표, 말풍선 채팅
- 3D 마을: 원형 트랙(출발 아치·가로등·🚀 부스터), 분수 광장과 꽃밭, 벚꽃나무
  - 🛹 스케이트파크(펀박스·킥커·메가 램프), 🌈 연못 위 무지개 다리(물에 빠지면 느려짐)
  - 🎡 관람차, 풍차, 열기구, 💫 점프대 앞 공중 링(통과 시 ⭐+3), ⭐ 별 모으기
- ❄️ 두 번째 맵 **눈꽃 설산** (로비에서 맵 선택, 맵마다 접속자 따로)
  - 진짜 언덕 지형(내리막은 빨라지고 오르막은 느려짐), 🚡 움직이는 리프트로 정상까지, 얼음 호수(미끄러짐)
  - 스키점프·공중 링, 통나무집(굴뚝 연기)·이글루·눈사람, 내리는 눈, 오로라
- ⏱️ 타임어택: 마을은 출발 아치부터 트랙 한 바퀴(체크포인트 4개), 설산은 슬라럼 다운힐(게이트 놓치면 +2초)
  - 맵별 타임어택 랭킹
- 🔔 따릉따릉 벨(T): 근처 사람에게 소리와 말풍선, 🔊 효과음(점프·별·링·묘기·꽈당·부스터·첨벙 등)과 음소거
- 🚴 조작감: 출발이 힘찬 페달 토크, 관성 주행(구름·공기 저항), 속도에 따른 회전 반경, 부드러운 핸들 입력
  - 원심력만큼 기울기, 페달 안 밟으면 크랭크 정지(픽시는 계속 돎), 출발 시 일어서서 밟기, 브레이크 시 앞 숙임, 착지 쿠션·화면 흔들림
  - 🌀 드리프트(브레이크+방향): 뒷바퀴가 미끄러지며 스키드 자국, 길게 하면 점수
  - 속도에 따라 넓어지는 시야, 코너 안쪽을 보는 카메라, 속도선, 바람·스키드 소리
  - 휴대폰 아날로그 핸들, 🎮 게임패드(왼쪽 스틱 핸들, RT 페달, LT 브레이크, A 점프, X/B/Y/LB/RB 묘기)
- 🤸 자전거 묘기 (공중에서): 🔄 백플립(Q) · 🔃 프론트플립(F) · 🌀 360 스핀(E) · 🦸 슈퍼맨(G) · 🙌 노핸드(R)
  - 연속 묘기 = 콤보 배율, 체공 시간 보너스, BMX·외발·세발 등은 배율 추가
  - 다 돌기 전에 착지하면 💥 꽈당! 잠시 못 움직임
  - 묘기 점수 랭킹
- 💾 기록 자동 저장: 별·총 주행거리·최고 기록·탄 횟수·산 아이템이 브라우저에 연결돼 계속 유지 (20초마다 + 나갈 때)
  - "다른 기기에서 이어하기" 코드로 다른 폰/PC에서도 그대로
- 🛠️ 차고: 모은 ⭐ 별로 자전거 꾸미기 구매·장착 (다른 사람에게도 보임)
  - 프레임 도색(무지개·황금·크롬…), 바퀴 림(네온·불꽃…), 액세서리(깃발·헤드라이트·하트 풍선·천사 날개), 꼬리 효과(반짝이·하트·무지개), 동승 펫(오리·고양이·강아지)
  - 가격·잔액 확인은 서버 함수에서 처리
- 최장 거리 랭킹 ("그만 타기" 시 10m 이상이면 저장)
- 모바일 터치 컨트롤

## 바로 플레이
https://bicycleroers.vercel.app (Vercel, 브랜치에 push하면 자동 배포)

## 실행
```bash
npm install
cp .env.example .env.local   # yahomi 프로젝트 URL / publishable key
npm run dev
```

## DB
`supabase/migrations/` 의 스키마가 yahomi 프로젝트에 적용되어 있습니다 (`bike_chat`, `bike_rides`, RLS: 누구나 읽기/쓰기만, 수정·삭제 불가).
